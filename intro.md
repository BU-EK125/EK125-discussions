# EK125 Discussion Notebooks

This is a companion site to the main [EK125 course site](https://BU-EK125.github.io/EK125/intro.html), collecting the interactive notebooks used in weekly discussion sections -- worked examples, live coding walkthroughs, and review material (including exam/quiz review) covered in section.

Each notebook is a runnable Jupyter notebook. Look for the 🚀 rocket icon in the top-right corner of a page (next to the download button); click it, then **Colab**, to open that notebook directly in [Google Colab](https://colab.research.google.com) and experiment with the code yourself.
