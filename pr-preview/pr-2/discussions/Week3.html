3. Review of Selection Statements#

Selection statements allow a program to choose which code to run based on conditions. Python uses if, elif, and else for decision-making. Check out the simple if statement example below.

temperature = 32

if True:
    print("Water is frozen.")

Water is frozen.

Check out the if-else statement example below.

temperature = 75

if False:
    print("Water is frozen.")
else:
    print("Water is not frozen.")

Water is not frozen.

Check out the if-elif-else statement example below. When there are multiple possible conditions, use elif.

temperature = 212

if temperature <= 32:
    print("Water is frozen.")
elif temperature < 212:
    print("Water is liquid.")
else:
    print("Water is boiling.")

Water is boiling.

The Difference Between if and elif#

When writing code, you will often need to make choices. A common question is: “Why can’t I just use a bunch of if statements? Why do I need elif?”

There are two main reasons: Logic and Efficiency.

1. Logic (Mutual Exclusivity)#

  • Multiple if statements: Every single if statement is checked, regardless of what happened before it. If you have three if statements and all three conditions are true, all three blocks of code will run.

  • elif statements: These are connected together. Python only checks an elif if the previous if (or elif) was False. As soon as one condition is met, Python executes that block and skips the rest.

2. Efficiency#

  • If you use elif, the computer stops working as soon as it finds the answer.

  • If you use multiple ifs, the computer wastes time checking conditions even after it already found the answer.

# THE WRONG WAY: Using multiple independent 'if' statements
# Scenario: Assigning a letter grade based on a score.

score = 95

print(f"Checking grade for score: {score}...")

if score >= 90:
    print("You got an A!")

if score >= 80:
    print("You got a B!")

if score >= 70:
    print("You got a C!")

if score >= 60:
    print("You passed.")

print("--- Done ---")

Checking grade for score: 95...
You got an A!
You got a B!
You got a C!
You passed.
--- Done ---

# ✅ THE RIGHT WAY: Using 'if' and 'elif' (Mutually Exclusive)

score = 95

print(f"Checking grade for score: {score}...")

if score >= 90:
    print("You got an A!")
elif score >= 80:
    # This only runs if score is NOT >= 90
    print("You got a B!")
elif score >= 70:
    # This only runs if score is NOT >= 90 AND NOT >= 80
    print("You got a C!")
elif score >= 60:
    print("You passed.")
else:
    print("You failed.")

print("--- Done ---")

Checking grade for score: 95...
You got an A!
--- Done ---

4. Combining Comparisons, Booleans, and Selection Statements#

In practice (and today’s quiz!), these concepts are almost always used together. Check out the example below.

temperature = 75
is_sunny = True

if False and (is_sunny):
    print("It's a great day for the beach!")
else:
    print("It's not a great day for the beach.")

It's not a great day for the beach.

Check out the nested if statement example below.

temperature = 100
is_sunny = True
uv = 6

if True:
  if uv > 5:
    print("It's a great day for the beach - make sure to wear sunscreen!")
  else:
    print("It's a great day for the beach - no sunscreen neccessary.")
else:
    print("It's not a great day for the beach.")

It's a great day for the beach - make sure to wear sunscreen!
