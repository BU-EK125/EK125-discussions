Discussion Week 4 Modules - Loops - Nested Loops#

Class 5: Importing Modules and Basic Loops#

Introduction#

  1. Importing modules - accessing additional functions and capabilities beyond basic Python

  2. Loops - repeating code automatically to handle repetitive tasks

These two concepts work together beautifully: loops let you repeat operations, and modules give you interesting operations to repeat! We’ll start with imports so you can use them in today’s practice problems.

Part 1: Importing Modules#

What is a Module?#

So far, you’ve been using Python’s built-in functions like print(), input(), len(), and type(). These are always available. But Python has many more functions organized into modules (also called libraries) that you can access when you need them.

Think of modules as specialized toolboxes:

  • math - mathematical functions like square root, trigonometry, constants like π

  • random - generating random numbers and making random choices

  • time - working with dates, times, and adding delays

  • os & sys - interacting with your operating system and files

How to Import: Basic Syntax#

To use functions from a module, you must first import it.

Method 1: Import Specific Functions (Recommended for Beginners) from module_name import function_name This imports just the function(s) you need, and you can use them directly.

# Method 1: Import Specific Functions
from random import randint

# Now you can use randint directly
dice_roll = randint(1, 6)
print("You rolled:", dice_roll)

# To import multiple functions from the same module:
from random import randint, random, choice

# Now you can use all three functions
num1 = randint(1, 10)      # Random integer from 1 to 10
num2 = random()            # Random float from 0.0 to 1.0
fruit = choice(['apple', 'banana', 'orange'])  # Random choice from list

print(f"Num1: {num1}, Num2: {num2:.2f}, Fruit: {fruit}")

You rolled: 5
Num1: 4, Num2: 0.85, Fruit: banana

Method 2: Import the Entire Module#

import module_name This imports the whole module, and you use functions by prefixing them with the module name. This is useful to avoid naming conflicts.

Method 3: Import with an Alias (Nickname)#

import module_name as nickname This is common for modules with long names.

⚠️ Important: Avoid from module import * This imports everything. It creates a messy namespace and makes debugging harder.

# Method 2: Import Entire Module
import random

# Use the module name before each function
dice_roll = random.randint(1, 6)
probability = random.random()
print("Rolled:", dice_roll)
print("Probability:", probability)

# Method 3: Import with Alias
import random as rnd

dice_roll = rnd.randint(1, 6)
print("Rolled with alias:", dice_roll)

Rolled: 5
Probability: 0.7185890918841704
Rolled with alias: 1

The random Module#

Here are the key functions:

  • randint(a, b): Generates a random integer from a to b (inclusive on both ends).

  • random(): Generates a random floating-point number from 0.0 (inclusive) to 1.0 (exclusive).

The math Module#

For more advanced math operations like square roots and Pi.

from random import randint, random
from math import sqrt, pi

# --- Random Examples ---
# Roll a six-sided die
roll = randint(1, 6)
print("Rolled:", roll)

# Random decimal between 0 and 100
percentage = random() * 100
print(f"Percentage: {percentage:.2f}%")

# --- Math Examples ---
# Calculate area of a circle
radius = 5
area = pi * radius**2
print(f"Area of circle: {area:.2f}")

# Calculate square root
number = 16
root = sqrt(number)
print(f"Square root of {number} is {root}")

Rolled: 3
Percentage: 49.20%
Area of circle: 78.54
Square root of 16 is 4.0

Part 2: For Loops#

For loops are used to repeat statements a specified number of times or to iterate over a sequence.

Loops using range#

The range(n) function generates a sequence of numbers from 0 up to (but not including) n. Structure:

for itervar in range(n):
    action

# Basic loop repeating an action 5 times
print("Start Loop:")
for i in range(5):
    print('!', end='')
print('\nOK')

Looping through sequences#

A for loop can be used in Python to iterate through the items in any sequence (like a list or a string), and perform the same action for each one.

Calculating Running Sums#

A useful application of a loop is to calculate a running sum. A running sum typically starts at 0, and then numbers are added to the sum one at a time.

Combining Loops with Random Numbers#

Now that you know about both imports and loops, you can create programs with interesting random behavior.

# Calculating a running sum
runsum = 0
for i in range(6):
    runsum = runsum + i
print('The sum of 0 through 5 is', runsum)

# Summing values from a list
runsum = 0
for n in [4, 33, 11]:
    runsum = runsum + n
print('The sum of the list is', runsum)

print("-" * 20)

# Random Number Loop
from random import randint

# Simulate rolling a die 5 times
print("Rolling a die 5 times:")
for i in range(5):
    roll = randint(1, 6)
    print(f"Roll {i+1}: {roll}")

Part 3: Conditional Loops (While)#

A while loop repeats the action as long as an expression is True. Structure:

while expression:
    action

# Basic while loop
x = 2
while x < 5:
    x = x + 1
    print(x)

print('!')

'''
# While loop with else
# The else block runs when the condition becomes False
x = 2

    print(x)
else:
    print('We are done at', x)

Error Checking#

Error-checking generally involves continuing to prompt the user until a valid value is entered.

Note: When running the code below, you will need to type into the input box that appears.

# Error Checking Example
# Try entering a negative number first to see the loop work!

number = input('Enter a positive number: ')
number = float(number)

while (number <= 0):
    number = input('Seriously! Enter a positive number: ')
    number = float(number)

print('Thanks for entering', number)

Seriously! Enter a positive number: -11.1
Seriously! Enter a positive number: 3
Thanks for entering 3.0

Counting in a while loop#

It is often useful to count how many times the action ended up being executed. We can use a counter variable initialized before the loop.

counter = 0
number = input('Enter a positive number: ')
number = float(number)
counter = counter + 1

while (number <= 0):
    number = input('Seriously! Enter a positive number: ')
    number = float(number)
    counter = counter + 1

print('Thanks for entering', number)
print('It took you', counter, 'tries.')

Enter a positive number: -9
Seriously! Enter a positive number: 33
Thanks for entering 33.0
It took you 2 tries.

Nested Loops#

Nested loops#

A nested loop is one loop inside of another.

  • Outer Loop: The first loop.

  • Inner Loop: The loop inside the action of the outer loop. The inner loop completes all its iterations for every single iteration of the outer loop.

# Nested loop iterating over words and then characters
wordlist = ['hello', "hi", 'ciao']
for myword in wordlist:
    for c in myword:
        print(c, end = ' ')
    print() # Newline after each word
print("That's it!")
'''
print("-" * 20)

# Nested loop with range (Creating a rectangle of stars)
for num in range(3):
    print(f'{num}:', end=' ')
    for n in range(5):
        print('*', end='')
    print()
'''

Varying the Inner Loop#

We can make the inner loop depend on the outer loop variable to create shapes (like triangles).

We can also nest while loops inside for loops (e.g., asking for input 3 distinct times, with error checking for each).

print("Triangle Pattern:")
for num in range(3):
    print(f'{num}:', end=' ')
    for n in range(num+1):
        print('*', end='')
    print()

print("-" * 20)

Using if Inside a Loop#

In practice, we often want the action to change depending on the current value of the loop variable.

Randomness and Reproducibility#

In engineering, results must be repeatable.

  • Pseudo-random numbers: Generated by a mathematical formula.

  • Seed: A starting point for the formula. If you set the seed, you get the same random numbers every time.

# Using IF inside a LOOP (Even/Odd check)
print("Even/Odd Check:")
for n in range(5):
    if n % 2 == 0:
        print(n, "is even")
    else:
        print(n, "is odd")

    if n < 2:
      break

x = 0
while x < 3:
  if x % 2 == 0:
    print(x, "is even")
  else:
    print(x, "is odd")
  x = x + 1
print("-" * 20)

# Randomness and Reproducibility
import random

random.seed(42)  # Set seed

print("Run 1 (Seed 42):")
print(random.randint(1, 100))
print(random.randint(1, 100))

# Resetting seed to show reproducibility
random.seed(42)
print("Run 2 (Seed 42 again):")
print(random.randint(1, 100)) # Will match the first number above
print(random.randint(1, 100)) # Will match the second number above
