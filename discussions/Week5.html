🟦 Section 2: Sequences#

  • Indexing starts at 0

  • Indexing is inclusive of the start index and exclusive of the end index

  • Negative indexing works from the end

    • -1 is the index of the last element

  • len() gives length

  • Strings are immutable

    • In place changes are not allowed

    • Modification creates a new object

    • String methods return new strings

  • Lists are mutable

    • Elements may be added, removed, and changed after the list is already created.

  • Tuples are immutable

    • Tuples do not have methods, like append() and pop(), which are available with lists to modify their contents in place.

    • To modify a tuple, you would have to create an entirely new tuple.

🟦 Section 5: While Loops#

While loops are used when:

  • You don’t know how many iterations are needed

  • Loop continues until condition becomes False

Structure:

while condition:
    code

Example

thirsty = True
while thirsty:
    print('You should drink water.')
    thirsty = False

You should drink water.

🟦 Section 6: Nested Loops#

A loop inside another loop.

Common uses:

  • Grids

  • Tables

  • Patterns

  • performing multiple replicates of the same action, such as repeats of an experiment

# GO OVER RANDOM FIRST, THEN DO THIS EXAMPLE


# We have 15 students, if they each flip a coin 5 times, how many heads will we get?
import random

random.seed(42)

students = 15
majority_heads = 0

for i in range(students):
    heads = 0
    for j in range(5):
        flip = random.randint(0, 1)  # 0 = tails, 1 = heads
        if flip == 1:
            heads += 1 #heads = heads + 1
    if heads >= 3:
        majority_heads += 1

print(f"Of {students} experiments, {majority_heads} had more heads than tails.")

Of 15 experiments, 6 had more heads than tails.

🟦 Section 7: Random Numbers#

import random
random.seed(10)
random.randint(a, b)

Generates an integer BETWEEN a and b (inclusive). The random.seed() function ensures that the same sequence of pseudo-random numbers is generated each time the program runs, provided the same seed value is used.

import random
a = 7
b = 8
#random.seed(10)
